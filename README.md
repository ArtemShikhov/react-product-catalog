# Полка

SPA-каталог для тестового задания на React и TypeScript. Zustand хранит загруженные товары и действия пользователя. Избранное, новые карточки, правки и удаления сохраняются в `localStorage` текущего браузера.

## Запуск

Понадобятся Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Для проверки типов и сборки:

```bash
pnpm typecheck
pnpm build
pnpm preview
```

## Маршруты

| Путь | Возможности |
| --- | --- |
| `/products` | Список, избранное, удаление, поиск при вводе, категории, сортировка и пагинация |
| `/products/:id` | Полное описание, изображения, цена и доступные характеристики |
| `/create-product` | Создание товара и проверка обязательных полей |
| `/products/:id/edit` | Редактирование товара той же формой |

Фильтры, сортировка и номер страницы хранятся в URL. Ссылка «В каталог» сохраняет их при переходе из карточки. Карточка открывается по клику, а кнопки избранного и удаления работают отдельно. Все цены указаны в долларах США, как в исходном каталоге.

## Данные и код

- `src/features/products` — типы, адаптер API и Zustand store.
- `src/pages` — страницы каталога, товара и общей формы.
- `src/components` — карточка, изображения, пагинация и состояния загрузки.
- Товары запрашиваются из [DummyJSON](https://dummyjson.com/docs/products). Если API недоступен, приложение загружает зафиксированный снимок из `public/catalog-snapshot.json`. CDN DummyJSON обслуживает остальные фотографии, а фотографии первой страницы включены в сборку.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в поле **Source**. Workflow `Deploy to GitHub Pages` запускается при push в `main` и вручную из **Actions**. Он передаёт Vite базовый путь сайта и публикует `dist/`.

Для прямых переходов по внутренним ссылкам GitHub Pages отдаёт приложение через `404.html`. React Router открывает нужный маршрут после загрузки. Сам HTTP-ответ при прямом переходе имеет статус 404, предусмотренный этим механизмом GitHub Pages.
